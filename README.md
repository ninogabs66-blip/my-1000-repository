# Grade Calculator

**Name:** RETON,NINO
**Section:** IT3R4

## Description
This is a simple JavaScript program that calculates the average of three grades and determines whether a student passed or failed.

## How to Run
1. Install Node.js on your computer.
2. Open CMD in the project folder.
3. Run the following command:

   `node grade-calculator.js`
